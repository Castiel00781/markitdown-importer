# Changelog

## 0.1.0

### Added

- Native Obsidian document import workflow
- PDF conversion
- Offline Persian, Arabic, and English OCR fallback for scanned PDFs
- Self-contained OCR resources compatible with three-file BRAT installation
- DOCX conversion
- HTML conversion
- TXT and Markdown import
- CSV-to-Markdown conversion
- Persian and Arabic text normalization
- Experimental RTL PDF line reconstruction
- Duplicate reversed-line detection
- Vault output selection
- Native settings tab
- Local-only processing
- Manual testing package

### Known limitations

- Desktop only
- OCR is intended for printed text and may be inaccurate for handwriting or complex image layouts
- PPTX and XLSX are not yet implemented
- YouTube transcript import is not included in this version
- Complex PDF layouts may require further reconstruction improvements
- RTL correction is experimental for PDFs with custom font encodings
